# Aim Training Game

A browser-based aim training game to improve mouse precision and reaction time. Click on randomly appearing circles as fast as you can to increase your score!

## Features

- **Multiple Time Modes**: Choose between 10, 20, or 30 second game sessions
- **Dynamic Targets**: Circles appear in random positions with varying sizes and colors
- **Score Tracking**: Keep track of how many targets you hit during each session
- **Responsive Design**: Clean and simple UI that works across different screen sizes
- **Restart Functionality**: Play again instantly with the restart button

## How to Play

1. Open `index.html` in your browser
2. Click "Start game"
3. Select your preferred time duration (10, 20, or 30 seconds)
4. Click on the circles as they appear to score points
5. Try to get the highest score before time runs out!
6. Click "Play Again" to restart

## Installation

No installation required! Simply clone the repository and open the HTML file:

```bash
git clone https://github.com/humblezxc/aim-game.git
cd aim-game
```

Then open `index.html` in your preferred web browser.
